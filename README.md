### Prerequisites
- Docker & Docker Compose
- Java 21
- Maven (or Maven Wrapper)

### 1. Clone Repository

```bash
git clone https://github.com/PashalisKoukos/Foodie-app.git
cd Foodie-app
```

### 2. Start Docker Containers

```bash
docker compose up -d --build
```

### 3. Check Running Containers

```bash
docker compose ps
```

### 4. Build Project with Maven

```bash
./mvnw clean install
```

### 5. Run Application

```bash
./mvnw spring-boot:run
```

### 6. Stop Docker Containers

```bash
docker compose down
```
